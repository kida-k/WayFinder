# WayFinder Project

Welcome to the WayFinder road trip planner. This project is organized into two main parts:

## 📁 Project Structure

- **`/frontend`**: The functional Expo React Native application. This is where the mobile UI and app logic reside.
- **`/backend`**: The Node.js Express server that integrates with Google Maps and AI for route suggestions.

## 🚀 Getting Started

### 1. Frontend (Mobile App)
Navigate to `/frontend` to run the mobile application:
```bash
cd frontend
npm install
npx expo start --web
```

### 2. Backend (API Server)
Navigate to `/backend` to run the server:
```bash
cd backend
npm install
npm start
```

## 🛠️ Tech Stack
- **Frontend**: React Native, Expo, Lucide-React-Native, Reanimated.
- **Backend**: Node.js, Express, Axios, Google Maps API, OpenAI (via OpenRouter).
